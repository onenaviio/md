# Просмотрщик md-документации — дизайн

**Дата:** 2026-06-11
**Статус:** одобрено

## Цель

Минимальное статичное приложение для отображения markdown-документации из
`src/docs`. Слева сайдбар со списком файлов, сгруппированных по папкам-разделам
(папка `Extranet API` → 3 файла). Клик по файлу открывает его рендер.

## Архитектура

### Layout и роутинг
- `App.vue` — layout: фиксированный сайдбар слева + область контента (`<router-view>`).
- Роуты:
  - `/` → редирект на первый документ.
  - `/doc/:id` → `DocView`, где `id` — закодированный путь файла относительно
    `src/docs` без расширения (например `Extranet API/endpoint-availability`).
- Дефолтные `HomeView`, `AboutView`, `HelloWorld.vue` удаляются.

### Загрузка документов (авто из файловой системы)
- `vue.config.js`: правило для `.md` → `type: 'asset/source'` (сырые строки).
- `src/shims-md.d.ts`: `declare module '*.md'` для TypeScript.
- `src/docs/index.ts`:
  - `require.context('./', true, /\.md$/)` сканирует `src/docs`.
  - Строит дерево `Section[]`, где `Section = { title: string; docs: Doc[] }`,
    `Doc = { id: string; title: string; raw: string }`.
  - `title` документа — первый заголовок `# …` из md (фолбэк: имя файла).
  - `title` раздела — имя папки. Файлы в корне `src/docs` (если появятся) —
    в раздел без заголовка / «Документы».
  - Экспорт: `sections`, `findDoc(id)`, `firstDocId`.

### Компоненты
- `SidebarNav.vue` — рендер дерева: раздел = сворачиваемая «папка»
  (по умолчанию развёрнута), файлы = `router-link` на `/doc/:id`.
  Активный пункт подсвечивается.
- `DocView.vue` (view) — берёт `id` из роута, через `findDoc` получает `raw`,
  рендерит в HTML и вставляет через `v-html`. Если документ не найден — заглушка.
- `src/services/markdown.ts` — настроенный `markdown-it` (`html`, `linkify`,
  GFM-таблицы включены по умолчанию) + `highlight.js` в опции `highlight`
  для подсветки код-блоков.

### Поток данных
Webpack инлайнит все `.md` как строки при сборке → `src/docs/index.ts` строит
дерево один раз при импорте → `SidebarNav` и `DocView` читают из него.
Никакого API, состояние не требуется (Vuex не задействуется).

## Зависимости
- Добавить: `markdown-it`, `highlight.js`, `@types/markdown-it` (dev).

## Стили
- Глобальный стиль документа в `DocView` (или подключённый CSS): типографика,
  таблицы (границы, паддинги), код-блоки (фон, моноширинный шрифт),
  тема highlight.js (например `github.css`).

## Проверка
Тест-раннера в проекте нет. Проверка вручную:
`yarn serve` → открыть приложение → раздел «Extranet API» развёрнут, видны 3
файла → клик по каждому открывает рендер с корректными таблицами и код-блоками.

## Вне рамок (YAGNI)
- Поиск по документам, оглавление внутри документа, тёмная тема,
  динамическая загрузка с бэкенда, редактирование.
