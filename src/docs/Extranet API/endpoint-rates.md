# Эндпоинт площадки: получение тарифов объекта (`/rates`)

> **Реализуется на стороне Площадки.** Аналог `/update-connection` (notify-connection),
> но в ответ возвращает данные — список тарифов объекта.

RealtyCalendar будет отправлять запрос на этот эндпоинт, чтобы получить **все тарифы,
привязанные к объекту на стороне Площадки**. Запрос выполняется при настройке/актуализации
интеграции объекта в личном кабинете отельера: RealtyCalendar забирает тарифы площадки,
отображает их в менеджере каналов и сохраняет соответствия (в т.ч. присвоенные площадкой
`id`).

## Запрос (Request)

URL: `POST /rates`

| Параметр | Положение | Тип | Пример | Описание |
|----------|-----------|-----|--------|----------|
| `auth_token` | query (url) | string | `abcdefg` | Идентификатор пользователя |
| `sign` | query (url) | string | `abcdefg` | Подпись сообщения ([подробнее](#подпись-сообщения)) |
| `accommodation_id` | body (json) | string | `123456` | Внешний ID объекта (идентификатор в системе Площадки) |

## Ответ (Response)

Запрос считается успешным, если вернулся ответ с:

- кодом 200-299
- хедером `Content-Type: application/json`
- телом со списком тарифов объекта в поле `rates`

В остальных случаях мы пытаемся отправить запрос еще 7 раз (всего произойдет 8 попыток).

Тело ответа — объект с массивом `rates`. Каждый элемент описывает один тариф объекта:

| Поле   | Тип | Пример | Описание |
|--------|-----|--------|----------|
| `id`   | string | `RATE-001` | ID тарифа в системе Площадки (используется для матчинга с тарифом RealtyCalendar) |
| `name` | string | `Базовый` | Название тарифа |

Пример тела ответа:

```json
{
  "rates": [
    {
      "id": "RATE-001",
      "name": "Базовый"
    },
    {
      "id": "RATE-002",
      "name": "Невозвратный"
    }
  ]
}
```

> Если у объекта нет тарифов, возвращается пустой список: `{ "rates": [] }`.

## Примеры запроса

Пример для cURL

```bash
curl 'http://<your_host>/rates?auth_token=CQqK8A4WGSsIWXeivG459pe&sign=866ac488560d4e6c15c83559b8c56994' \
  -X 'POST' \
  -H 'Content-Type: application/json' \
  --data-raw '{ "accommodation_id": "123456" }'
```

## Коды ошибок

| Код | Описание |
|-----|----------|
| 200–299 | Успех — тело содержит `{ "rates": [...] }` |
| 4xx | Ошибка запроса (неверная подпись, неизвестный `accommodation_id` и т.п.) |
| 5xx | Внутренняя ошибка Площадки |

При любом ответе вне диапазона 200–299 запрос повторяется (всего до 8 попыток).
